# 工作台配置与对话扩展（2026-10-08）

此扩展回应内部试用中的两个缺口：配置只能查看，以及一次输入会立即生成音乐。它不改写原 SDD-06 的历史验收结论；旧的六阶段自动运行仍可用于基线对比。

## 已确认的交互

1. 内部人员可编辑系统提示词、记忆理解指令、单次理解最多轮数（1–3）和单轮输出预算（512–2048 tokens），保存为新版本。理解预算仍为 45 秒；供应商、模型地址、密钥和工具实现继续由服务端控制。
2. 新测试会话锁定创建时的完整配置快照；编辑配置不改变已开始的对话或历史运行。重跑复制原照片和故事，可选择当前或原配置；互动会话的重跑从空对话开始。
3. 上传照片和首句后，用户可与 Agent 多轮讨论。Agent 不自动生成音乐。用户整理意图，阅读结构化摘要并按确认按钮，才执行生成。
4. 生成后同一会话可继续自然语言讨论；再次整理并确认修改意图才调用配乐服务。每次成功生成产生独立音乐版本，保留此前版本及其意图摘要。
5. 讨论与运行记录保留 30 天。到期前可刷新继续；到期后沿用既有私有照片清理与访问拒绝。演示、真实理解、真实配乐及 QQ mock 仍需准确标识。

## 验收点

- 未保存的编辑不影响新运行；保存后新运行使用新版本，旧运行快照与摘要不变；并发编辑会收到冲突提示。
- 互动模式下，直接调用原执行接口不能绕过意图确认。用户多轮讨论后，确认之前音乐阶段保持未开始。
- 同一输入至少两轮讨论后，确认意图生成；再至少两轮讨论后确认修改，出现两个可区分、可试听的音乐版本。失败不会覆盖已有版本。
- 刷新、重进、同时发送和会话过期场景下，消息与音乐版本顺序可靠；未授权访问不返回提示词、照片、消息或音频信息。
- 旧自动运行、重跑、对比以及用户端 01–09 页面仍可用。

## 实现边界

工作台配置版本和对话只由服务端口令会话访问。新表启用 RLS，并撤销 anon/authenticated 权限；对话按运行记录外键级联清理。每次消息、意图整理或修改生成通过数据库租约串行化。外部凭证不进入配置版本、对话内容或浏览器响应。
