用户在本地和正式域名上传照片后均看到“Agent 本轮未得到有效回复”。只读核对两条草稿：照片分别已保存 1 张和 3 张，首轮均为 `failed / INVALID_RESULT`。本地使用冻结的 `qwen3-vl-flash` 对原草稿执行内存诊断，供应商返回 HTTP 404 `model_not_found`；同一业务空间、同一密钥的模型列表返回 200，仅列出 `qwen3-vl-plus`，直接调用 Plus 返回 200。正式草稿冻结了同一北京业务空间和 Flash 模型；由于当前 Vercel 团队连接返回 403，未读取正式运行日志，线上具体供应商错误仍需发布后复验。

如果供应商将来仍返回 `model_not_found`，用户端会显示“当前视觉模型不可用”，服务端只记录错误类别和轮数，避免再把供应商配置问题误报为普通回复格式错误。
