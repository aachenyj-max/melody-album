# 2026-10-09 · 上传后回复格式误判修复

- 用户线上反馈上传照片后出现“Agent 本轮未得到有效回复，请重试”。只读核对发现照片已经保存，首轮状态为 `failed / INVALID_RESULT`，不是上传失败或超时。
- 修复前使用同一照片、冻结配置与首轮消息，在本地真实 Pi/Qwen 执行器连续复现两次失败。模型正常结束且有文字输出，但改写后仍有两个问号：一句不确定的场景描述与一个实际追问。最终格式检查将整轮拒绝。
- 修复强化文字改写要求，并在改写时关闭方向卡工具。若仍有多个疑问句，保留陈述句和最后一个追问，删除前面的疑问句；不把不确定推测改成确定事实。空回复、模型错误、非法方向卡和最终输出上限继续校验。服务端失败日志仅增加原因类别、轮数与长度，不记录照片、聊天正文或供应商凭证。
- 修复后，同一首轮真实调用两次成功；以相同照片和仅在内存补充的爵士/木贝斯要求验证，真实模型返回一张合法方向卡。上述调用未写回用户草稿，未执行音乐生成。
- 五项格式回归覆盖原两问号例子、已有单问句、英文问号的多次追问、无问号和空文本。TypeScript、变更文件 Biome、生产构建通过。
- 本次为本地修复和直接执行器验证，尚未发布线上，也未操作用户浏览器的重试按钮；不能将本地结果作为线上修复完成证据。Vercel MCP 日志读取返回 403，故未取得原线上调用的模型正文，根因结论来自同图重复复现。
