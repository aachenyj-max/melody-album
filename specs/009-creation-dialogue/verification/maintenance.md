# 草稿到期与媒体清理

2026-10-09，受控临时记录验证：expires_at 过期后先拒绝读取，随后维护删除草稿媒体和记录。通过隔离 undici 传输注入照片删除 503；本次维护 failed 计数增加，草稿仍存在；恢复传输后下一次维护删除成功。

removed 照片不再注入 Agent。未被快照引用的对象尝试即时删除；被已确认快照引用的照片在移除 active 后仍能从该快照读取，至草稿到期才回收。数据库保留元数据墓碑，删除失败由既有维护重试。

使用同一确认照片创建临时真实保存相册，随后清理原草稿；保存相册照片继续返回 200，与原照片字节完全一致。证明相册私有对象由既有保存流程独立持久化，不依赖草稿 URL。之后清理临时保存相册。

维护接入现有 token 保护的 `/api/albums/maintenance`，未增加公开清理接口；不改工作台表或 bucket。每轮最多扫描 100 条到期草稿与 100 条活动草稿，当前 MVP 数据量可覆盖；未验证超过该批量的长期清理吞吐。
