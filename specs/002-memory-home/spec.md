# 功能规格：音乐相册首页与历史记忆

**Feature Branch**: `002-memory-home`

**Created**: 2026-10-05

**Status**: Draft

## User Scenarios & Testing

### User Story 1 - 从首页开始创建音乐记忆 (Priority: P1)

用户进入音乐相册后，首页首屏清楚表达“上传照片，生成一段记忆”，并能直接进入创建流程。首页同时让用户知道这里是自己的音乐空间，而不是普通的歌曲列表。

**Why this priority**: 首页是用户端主入口，必须先验证产品价值主张和后续创建流程的入口是否清晰。

**Independent Test**: 在没有真实 Agent 或音乐服务的情况下打开首页，确认首屏可理解、创建按钮可操作，并能进入创建音乐相册的初始状态。

**Acceptance Scenarios**:

1. **Given** 用户首次进入音乐相册首页，**When** 页面完成加载，**Then** 用户能看到个人音乐空间的定位、创建音乐相册的主要文案和明确的创建入口。
2. **Given** 用户位于首页，**When** 用户点击“上传照片，生成一段记忆”或等价的创建入口，**Then** 应用进入创建流程的上传照片初始状态。
3. **Given** 用户刷新首页，**When** 页面重新加载，**Then** 创建入口仍然可见且无需先完成历史记忆浏览。

---

### User Story 2 - 浏览最近的音乐记忆 (Priority: P1)

用户可以在首页看到最近保存的音乐记忆摘要，并进入“我的音乐记忆”列表查看历史内容。每条记忆至少能让用户识别封面、标题、照片数量或照片预览、关联歌曲和日期。

**Why this priority**: 历史内容证明音乐相册是可再次打开的个人空间，也是保存动作之后的主要回访入口。

**Independent Test**: 使用稳定的演示数据打开首页和列表页，确认列表非空、信息可识别、刷新后内容不丢失，并能从列表进入详情。

**Acceptance Scenarios**:

1. **Given** 首页存在最近音乐记忆，**When** 用户浏览首页，**Then** 页面显示至少一条带封面、标题和日期的最近记忆摘要。
2. **Given** 用户点击“我的音乐记忆”或最近记忆区域，**When** 列表页打开，**Then** 页面显示按最近创建时间排列的记忆卡片，并保留进入详情的操作。
3. **Given** 用户位于记忆列表，**When** 用户点击一条记忆，**Then** 应用打开对应详情页，展示该记忆的照片、标题、歌曲和创建日期。
4. **Given** 用户连续刷新首页或列表页，**When** 演示数据重新加载，**Then** 页面仍显示相同的非空示例内容，且卡片信息不随机变化。

---

### User Story 3 - 识别未开放的导航与分享入口 (Priority: P2)

用户能看到探索/推荐、个人中心和分享入口在产品中的位置，但点击尚未实现的入口时不会被带入错误流程，也不会误以为分享已经生效。

**Why this priority**: 原型包含这些入口，保留位置有助于还原完整产品外壳，同时明确当前 MVP 的边界。

**Independent Test**: 从首页、列表和详情页查看底部导航及分享按钮，确认入口状态一致；点击不可用入口后得到明确提示或安全停留。

**Acceptance Scenarios**:

1. **Given** 用户位于首页或记忆列表，**When** 用户查看底部导航，**Then** 探索/推荐、音乐相册和个人中心的位置与当前选中状态清晰可辨。
2. **Given** 用户点击当前 MVP 未开放的探索/推荐或个人中心入口，**When** 操作完成，**Then** 页面显示“暂未开放”类明确反馈或保持当前页面，不出现空白页。
3. **Given** 用户位于记忆详情页，**When** 用户点击分享按钮，**Then** 页面显示分享能力尚未开放的明确占位反馈，不生成外部链接或改变相册数据。

### Edge Cases

- 历史记忆为空时，列表页显示可理解的空状态，并保留创建音乐相册入口；演示环境默认提供稳定的非空示例数据。
- 某条记忆缺少歌曲、照片或日期字段时，卡片和详情页显示明确的缺省文案或占位，不出现破损布局。
- 用户直接访问列表或详情页时，页面仍有明确标题、返回入口和可识别的内容边界。
- 视口较窄或系统字体较大时，标题、卡片、主要按钮和底部导航保持可读可操作，不出现明显横向滚动。
- 用户快速重复点击创建、列表或分享入口时，不产生重复页面、重复数据或错误提示堆叠。
- 尚未实现的入口被点击时，不应伪装成已完成的推荐、个人资料或真实分享。

## Requirements

### Functional Requirements

- **FR-001**: 首页 MUST 将“上传照片，生成一段记忆”作为首要创建任务，并提供可识别、可操作的创建入口。
- **FR-002**: 首页 MUST 展示音乐相册作为个人音乐空间的定位文案或等价信息，使用户理解照片、记忆和音乐之间的关系。
- **FR-003**: 首页 MUST 展示最近音乐记忆摘要；每条摘要至少包含封面或照片预览、标题和日期。
- **FR-004**: 应用 MUST 提供“我的音乐记忆”列表入口，列表 MUST 按最近创建时间展示记忆卡片，并允许进入详情。
- **FR-005**: 记忆详情 MUST 展示该记忆的标题、照片或照片预览、关联歌曲信息和创建日期；缺失字段 MUST 使用明确的缺省状态。
- **FR-006**: 首页、列表和详情 MUST 使用稳定的本地演示数据，使用户刷新后仍能看到一致且非空的示例内容。
- **FR-007**: 当没有可展示的历史记忆时，列表 MUST 显示空状态并保留创建入口，不得显示空白页面。
- **FR-008**: 应用 MUST 保留原型中的底部导航结构，并清楚标识当前所在入口；探索/推荐和个人中心在本阶段可为不可用占位。
- **FR-009**: 分享按钮 MUST 在详情页可见，但本阶段不得创建外部分享链接、调用真实分享能力或修改相册数据。
- **FR-010**: 未开放的导航入口 MUST 提供明确的未开放反馈或安全停留行为，不得进入无标题或无内容页面。
- **FR-011**: 首页、列表和详情 MUST 支持移动宽度下的阅读和操作，主要内容不得产生明显横向溢出。
- **FR-012**: 本阶段 MUST 保持与 SDD-00 建立的页面容器、标题层级、颜色、字体、间距和返回行为一致，不引入超出音乐相册 MVP 范围的新模块。

### Key Entities

- **音乐记忆**：用户保存或用于演示的一段个人记忆内容，包含标题、封面或照片、关联歌曲、创建日期和可选的一句话描述。
- **照片预览**：属于某条音乐记忆的照片或照片缩略图，用于列表摘要和详情展示，不在本阶段定义上传或持久化规则。
- **歌曲信息**：与音乐记忆关联的熟悉歌曲、推荐歌曲或 AI 配乐摘要，用于帮助用户识别该记忆的音乐表达。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 首次进入首页后，用户在 10 秒内能识别创建入口，并在 3 次点击以内进入上传照片初始状态。
- **SC-002**: 首页、记忆列表和详情三类页面均可从应用入口到达，且每类页面至少有一条可完成的演示路径。
- **SC-003**: 在连续刷新 5 次的情况下，首页和记忆列表始终显示同一组非空演示记忆，标题、封面、歌曲和日期不随机变化。
- **SC-004**: 评审者使用演示数据时，能在 1 分钟内从首页打开一条记忆详情，并在该页直接看到其标题、关联歌曲和日期。
- **SC-005**: 在至少 3 个常见移动视口宽度下，首页、列表和详情均无明显横向滚动，创建、列表和返回入口保持可操作。
- **SC-006**: 点击未开放导航或分享入口后，100% 的操作都得到明确占位反馈或安全停留，不产生外部链接、不写入业务数据。

## Assumptions

- 本阶段承接 SDD-00 的 App Shell、页面边界和导航约定，目标是形成可点击、可回访的首页与历史记忆体验。
- 首页、列表和详情使用稳定的本地 mock 数据；真实保存、用户隔离、照片上传和音乐服务由后续 SDD 接入。
- 演示数据至少包含两条音乐记忆，覆盖不同标题、封面/照片、歌曲和日期，便于评审列表和详情状态。
- 记忆默认按最近创建时间倒序展示；本阶段不提供排序、筛选、编辑、删除或重命名。
- 分享、探索/推荐和个人中心只保留入口位置与占位反馈，不属于本阶段的可用业务能力。
- 用户主要通过移动宽度访问，但页面需在桌面宽度保持可读；网络异常不影响本地演示数据展示。
- 本阶段不要求新增登录、数据库写入、Storage 上传或真实外部 API 调用。

## Out of Scope

- 照片上传、Agent 记忆理解、自然语言修正和故事输入。
- AI 配乐生成、QQ 音乐实时检索、播放控制和沉浸式播放。
- 真实 Supabase 持久化、用户认证、照片存储和用户间数据隔离。
- 分享链接、公开访问、评论、协作和自动事件归档。
- 记忆编辑、合并、拆分、删除、筛选和复杂搜索。
