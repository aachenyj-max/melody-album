# UI 导航契约：SDD-01

此契约描述用户可见页面及交互；不定义服务端 API。

| 地址/入口 | 输入或操作 | 可见结果 | 失败或边界 |
| --- | --- | --- | --- |
| `/` 首页 | 打开或刷新 | 个人音乐空间定位、明显的“上传照片，生成一段记忆”入口、最近记忆摘要 | 无演示记忆时仍显示创建入口 |
| 首页创建入口 | 点击 | 到达 `/create` 上传照片初始状态或 SDD-00 的明确创建占位 | 不进入空白页 |
| 首页“查看全部”/记忆导航 | 点击 | 到达 `/memories` | 可从列表返回首页 |
| `/memories` | 打开或刷新 | 按创建日期倒序展示稳定记忆卡片 | 无记录时显示空状态及创建入口 |
| 列表卡片 | 点击 | 到达 `/memories/{id}` | 不应跳到无关记录 |
| `/memories/{id}` | 直接打开或从列表进入 | 标题、照片、歌曲、创建日期和返回入口 | 未知 ID 显示未找到状态并可返回列表 |
| 底部探索/推荐、个人中心 | 点击或查看 | 明确“暂未开放”反馈或保持当前页面；当前入口状态可辨 | 不进入空白页，不产生业务写入 |
| 详情分享按钮 | 点击 | 明确提示分享尚未开放 | 不生成链接、不调用外部分享 |

## 原型映射

- `designs/ui/01-首页-音乐相册.png`：首页的创建主入口和最近记忆。
- `designs/ui/08-我的音乐记忆页.png`：列表卡片和导航选中态。
- `designs/ui/09-音乐相册详情页.png`：详情信息层级和分享占位。

原型中的分类、编辑、播放控制不在本阶段契约内；若保留图标，必须清楚表现为占位或给出未开放反馈。
